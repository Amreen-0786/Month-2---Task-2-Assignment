# PDF Report Generator

The task sheet asks for professional PDF reports from structured data, with headings, tables, totals, and optional date/logo/summary information. fileciteturn0file0L73-L83

## Install

From the repository root:

```powershell
pip install -r requirements.txt
```

## Run

```powershell
python pdf_report_generator.py --input sample_data.csv --output output\student_report.pdf
```

The PDF is created in the `output` folder.
